화면에서 누를 위치

EmailJS 대시보드 → Email Services → Add New Service → Gmail → Connect Account에서 pulynn01@gmail.com 계정에 연결합니다. 기존 서비스가 있으면 해당 서비스를 선택하세요. 서비스 편집 창의 Service ID를 확인하고 저장합니다. Public Key는 Account의 API Keys에서 확인합니다.

STEP 4 · 구글 → 네이버 자동 전달

화면에서 누를 위치

Gmail → 설정(톱니바퀴) → 모든 설정 보기 → 전달 및 POP/IMAP → 전달 주소 추가. 아래 주소를 등록한 뒤 네이버에 도착한 확인 메일의 인증 링크를 누릅니다. Gmail로 돌아와 검색창 오른쪽 검색 옵션 → 제목 조건 입력 → 필터 만들기 → 다음 주소로 전달을 선택합니다.

붙여넣을 값

전달 주소nalynnxx@naver.com
제목에 포함[문의]

문의 메일만 전달하려면 전체 메일 전달 대신 필터 전달을 사용하세요. EmailJS는 연결된 Gmail로 자신에게 보내므로 자기발신 메일에 전달 필터가 적용되지 않을 수 있습니다. 네이버로 도착하지 않으면 STEP 2 알림 템플릿의 Bcc에 네이버 주소를 입력하고 저장하세요. 전달과 Bcc가 모두 작동하면 중복 수신되므로 한 방식만 사용하세요.

STEP 5 · 문의 내역 분류

화면에서 누를 위치

Gmail 검색 옵션 → 제목에 아래 조건 입력 → 필터 만들기 → 라벨 적용 → 새 라벨을 선택합니다. 받은편지함에서 계속 보려면 받은편지함 건너뛰기(보관)는 선택하지 않습니다. 라벨만 모아 관리하려면 보관을 선택할 수 있습니다.

붙여넣을 값

제목 조건[문의]
라벨 이름 예시AI 교육 문의

STEP 4에서 만든 필터가 있다면 설정 → 필터 및 차단된 주소에서 같은 필터를 수정해 라벨을 추가하세요. 문의 처리가 끝난 기록은 동의문에 맞춰 처리 완료 후 1년 뒤 파기하도록 별도로 관리해야 합니다.

STEP 6 · 동작 테스트

화면에서 누를 위치

배포 홈페이지의 문의 폼에 본인이 확인할 수 있는 이메일을 입력하고 개인정보 동의 후 문의 보내기를 누릅니다. EmailJS Email History에서도 두 템플릿의 전송 결과를 확인합니다.

붙여넣을 값

문의 폼 주소https://ai-3-opal.vercel.app/#contact
테스트 문의 내용[설정 테스트] AI 교육 문의 폼 발송 확인입니다.
  1. Gmail에 접수 알림이 도착하고 문의 내용·동의 시각이 표시되는지 확인합니다.
  2. 입력한 문의자 이메일로 자동회신이 도착하는지 확인합니다.
  3. 네이버에서 전달 또는 Bcc 메일을 확인합니다.
  4. Gmail의 AI 교육 문의 라벨이 자동 적용되는지 확인합니다.

미수신 시 스팸함, 서비스 연결 상태, 템플릿 ID, Email History 오류와 발송 한도를 확인하세요. Account에서 도메인 허용 목록을 사용하는 경우 아래 사이트를 허용하세요. 이 문서는 설정 안내이며 실제 계정 설정을 자동으로 변경하지 않습니다.
